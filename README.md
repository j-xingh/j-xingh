### `01 / FIELD NOTES`

I'm interested in the moment when data, parameters, and code start doing something intelligent.

That curiosity pulled me into machine learning. I'm exploring deep learning, training models, working with data, and turning experiments into software people can actually use.

I don't want to stop at *"it works on my machine."* I want to understand why a model works, where it fails, and what it takes to ship it.

My UX/UI background gives me a second lens: the engineering matters, and so does the experience built around it.

**Current direction:** AI engineering · Applied ML · Useful software
